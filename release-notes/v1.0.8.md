# Minecraft Control Center v1.0.8

This maintenance release fixes the underlying cause of Crafty failing immediately after an
in-app MCC update: the administrator update helper was relaunching MCC with elevated process
and console state.

## Changes in this release

- Relaunches an updater-started elevated MCC instance through the signed-in user's Explorer
  session before initializing the application.
- Prevents Crafty from inheriting the update helper's closed console stream and exiting
  cleanly with exit code 0.
- Adds a guarded relaunch path that avoids loops on systems where Explorer is also elevated.
- Changes newly generated update scripts to restart MCC through Explorer after successful
  updates and rollback recovery.
- Keeps the reliable, console-preserving Crafty launch behavior used by the early releases.
- Retains the complete two-minute Crafty readiness monitor and explicit startup diagnostics.
- Retains verified multi-process Crafty shutdown, force-stop fallback, stale session-lock
  removal, and safe SQLite shared-memory recovery.
- Adds automated checks for standard-user relaunch configuration and generated updater
  scripts.

## Supported providers

- Server manager: Crafty
- Connection: PlayIt
- Launchers: Prism Launcher and TLauncher

## Installation

For a normal Windows installation, download and run:

`MinecraftControlCenter-Setup.exe`

For portable use, download and extract:

`MinecraftControlCenter.zip`

Windows 10 or later on a 64-bit PC is required.
