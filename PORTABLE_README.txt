Minecraft Control Center portable release
=========================================

Run MinecraftControlCenter.exe. On first launch, choose the folder that contains
crafty.exe. You can also place this executable directly beside crafty.exe, in which
case the server is detected automatically.

The app stores only its selected server-folder setting under:
%LOCALAPPDATA%\MinecraftControlCenter

Updates are downloaded from this project's GitHub Releases page. Each release must
include an asset named MinecraftControlCenter.zip.
