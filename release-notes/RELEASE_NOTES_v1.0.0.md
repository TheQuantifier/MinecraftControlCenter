# Minecraft Control Center v1.0.0

- Converted the existing Crafty Control Center into a maintainable standalone app.
- Added installed and portable modes with a remembered Crafty server folder.
- Added a GitHub Releases updater with automatic restart and UAC support.
- Added repeatable app, ZIP, and Inno Setup installer builds.
- Excluded live server worlds, logs, backups, credentials, and browser data.
