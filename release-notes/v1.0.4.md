# Minecraft Control Center v1.0.4

This maintenance release prevents stale Crafty session locks from blocking startup and
makes Minecraft Control Center uninstall completely, including its local application data.

## Changes in this release

- Detects when Crafty's `session.lock` PID has been reused by an unrelated Windows process.
- Removes the exact stale Crafty lock only after confirming that Crafty is not running, its
  dashboard is not listening on port 8443, and the lock did not change during validation.
- Preserves valid and unverifiable locks to avoid disrupting an active Crafty instance.
- Cleans up a stale Crafty lock after Minecraft Control Center safely stops Crafty.
- Closes only Edge or Chrome processes using Minecraft Control Center's isolated dashboard
  profile before uninstalling.
- Retries removal of `%LOCALAPPDATA%\MinecraftControlCenter`, including settings, browser
  data, cached icons, and update remnants.
- Removes recorded shortcuts, portable application files, rollback files, and temporary
  uninstall scripts.
- Adds automated self-tests for Crafty lock handling and uninstall-script generation.

## Supported providers

- Server manager: Crafty
- Connection: PlayIt
- Launchers: Prism Launcher and TLauncher

## Installation

For a normal Windows installation, download and run:

`MinecraftControlCenter-Setup.exe`

For portable use, download and extract:

`MinecraftControlCenter.zip`

Windows 10 or later on a 64-bit PC is required.
