# Minecraft Control Center v1.0.6

This maintenance release fixes an intermittent Crafty startup failure and makes the
startup state and error reporting accurately reflect what Crafty is doing.

## Changes in this release

- Launches Crafty directly as a hidden, console-free process without relying on the Windows
  shell.
- Uses Crafty's configured installation directory as its working directory.
- Keeps the Crafty control and batch buttons in the `Starting...` state for the complete
  two-minute dashboard readiness window instead of reverting after 20 seconds.
- Detects when the launched Crafty process exits before port 8443 becomes ready.
- Reports an early Crafty exit and its exit code instead of silently returning the control
  to `Start`.
- Distinguishes between an exited Crafty process, a startup timeout, and a running Crafty
  process whose dashboard has not become ready.
- Adds automated coverage for the exact Crafty process-launch configuration.
- Retains the verified force-stop, stale lock cleanup, and safe SQLite recovery introduced
  in v1.0.5.

## Supported providers

- Server manager: Crafty
- Connection: PlayIt
- Launchers: Prism Launcher and TLauncher

## Installation

For a normal Windows installation, download and run:

`MinecraftControlCenter-Setup.exe`

For portable use, download and extract:

`MinecraftControlCenter.zip`

Windows 10 or later on a 64-bit PC is required.
