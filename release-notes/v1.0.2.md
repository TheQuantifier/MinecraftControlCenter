# Minecraft Control Center v1.0.2

This patch fixes stale Windows shortcut icons after updating Minecraft Control Center.

## Changes in this release

- Added a version-specific shortcut icon file so Windows does not reuse an icon cached
  for an older executable at the same path.
- Existing desktop, Start menu, and app-created shortcuts that target Minecraft Control
  Center are repaired automatically when the app starts.
- Newly created shortcuts now reference the version-specific icon directly.
- Notifies Windows Explorer after shortcut repairs so the refreshed icon appears without
  rebuilding the system-wide icon cache.
- Keeps the executable, installer, background, and interface styling introduced in
  v1.0.1.

## Supported providers

- Server manager: Crafty
- Connection: PlayIt
- Launchers: Prism Launcher and TLauncher

## Installation

For a normal Windows installation, download and run:

`MinecraftControlCenter-Setup.exe`

For portable use, download and extract:

`MinecraftControlCenter.zip`

Windows 10 or later on a 64-bit PC is required.

## Included release assets
